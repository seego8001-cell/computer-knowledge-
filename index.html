💻 មូលដ្ឋានកុំព្យូទ័រ

ប្រព័ន្ធឌីជីថល

📖 មេរៀនទី១៖ តើកុំព្យូទ័រជាអ្វី?

កុំព្យូទ័រ គឺជាឧបករណ៍អេឡិចត្រូនិក ដែលអាចទទួលទិន្នន័យ ដំណើរការទិន្នន័យ រក្សាទុកទិន្នន័យ និងបង្ហាញលទ្ធផល។

📖 មេរៀនទី២៖ Hardware

Hardware គឺជាផ្នែករបស់កុំព្យូទ័រ ដែលយើងអាចមើលឃើញ និងប៉ះបាន។ ឧទាហរណ៍៖

  • 🖥️ Monitor
  • ⌨️ Keyboard
  • 🖱️ Mouse
  • 🧠 CPU
  • 💾 Hard Disk / SSD
  • 🧮 RAM

📖 មេរៀនទី៣៖ Software

Software គឺជាកម្មវិធី ដែលដំណើរការនៅលើកុំព្យូទ័រ ដើម្បីឱ្យអ្នកប្រើប្រាស់ អាចធ្វើការងារផ្សេងៗបាន។
